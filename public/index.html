          Typed Schema Specification (Zod & JSON Schema)
        

        

          The pipeline rigorously assesses every output against this typed schema. Any mismatch triggers targeted repair retries or the explicit human review path.
        

      


      

        
        

          

            
Cross-Field Validation Invariants

            

              

                1. Arithmetic Consistency:
                
abs((subtotal + tax_amount) - total_amount) ≤ 0.05

                
Guarantees line-item math and totals cannot diverge.

              

              

                2. Out-of-Domain Negative Zero-Tolerance:
                
is_valid_document === false → total_amount === null && invoice_number === null

                
Completely forbids hallucinating false billing fields on unrelated documents (recipes, weather, prose).

              

              

                3. ISO 8601 Date Formats & Chronology:
                
invoice_date & due_date ~ /^\d{4}-\d{2}-\d{2}$/ && due_date ≥ invoice_date

                
Enforces strict calendar standardization and ensures payment due date cannot precede issuance date.

              

              

                4. Itemized Math Refinement:
                
abs(quantity * unit_price - amount) ≤ 0.05

                
Validates line item unit rates against extended line item amounts.

          Production Pipeline Architecture & Failure Path
        

        

          Zero silent failures. How raw unstructured text is turned into validated structured records reliably.
        


        
        

          
          

            
1

            
Unstructured Ingestion

            
Messy text, noisy OCR scans, faxes, international invoices, or out-of-domain articles.

          


          

            
2

            
Schema-Constrained Generation

            
Entity parsing, currency recognition, itemized table parsing, and out-of-domain classification.

          


          

            
3

            
Strict Zod Validation

            
Evaluates types, regex dates, cross-field arithmetic checks (subtotal + tax = total).

          


          

            
4

            
Targeted Self-Healing

            
Injects exact error paths into feedback prompt. Retries extraction iteratively.

          


          

            
5

            
Explicit HITL Routing

            
Never silently accepted. Enqueued in review queue with full diagnostic audit trace.

          


        


        
        

          
          

            Key Reliability Guarantee: The pipeline strictly distinguishes between validated invoices, self-healed invoices, explicitly rejected out-of-domain documents, and routed review items. An invalid extraction is physically incapable of escaping into downstream data stores without either being repaired by the retry loop or explicitly approved by a human reviewer.
